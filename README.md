# BlancedCar

本项目是一个基于 **STM32F103C8T6** 的两轮自平衡小车控制系统。系统通过 **MPU6050姿态传感器** 获取车体倾角，通过 **编码器** 获取左右轮速度，通过 **串级PID控制算法** 计算电机输出，最终实现：

1. 小车直立自平衡；
2. 前进与后退速度控制；
3. 左右转向控制；
4. OLED实时数据显示；
5. 蓝牙串口在线调参与遥控；
6. 按键启停与LED运行状态指示。

---

## 一、项目简介

两轮平衡车本质上是一个典型的倒立摆控制系统。小车只有两个轮子与地面接触，车体在重力作用下天然不稳定，因此需要控制器实时检测姿态变化，并驱动电机前后运动，使车体维持在接近平衡的位置。

本工程采用的基本思路为：

* **MPU6050** 获取加速度与角速度；
* 通过 **互补滤波** 估计车体倾角；
* 使用 **角度环PID** 保持车体直立；
* 使用 **速度环PID** 控制前后运动；
* 使用 **转向环PID** 控制左右差速；
* 通过 **PWM+方向引脚** 驱动左右电机；
* 通过 **OLED与蓝牙串口** 完成调试、显示与交互。

---

## 二、工程整体功能说明

### 1. 系统总体功能

整个工程可以划分为四类任务：

#### 1）姿态检测任务

负责读取MPU6050原始数据，计算车体当前倾角，供平衡控制使用。

#### 2）闭环控制任务

根据角度、速度、转向误差计算PWM输出，控制左右轮运动，完成小车平衡与移动控制。

#### 3）人机交互任务

负责按键启停、OLED数据显示、蓝牙命令接收与PID参数修改。

#### 4）底层外设驱动任务

负责I2C、串口、定时器、PWM、编码器、电机方向控制等底层硬件接口。

---

### 2. 工程运行流程

工程整体启动流程如下：

1. 进入 `main()`；
2. 初始化OLED、MPU6050、蓝牙串口、LED、按键、电机、编码器、调试串口；
3. 初始化TIM1定时中断；
4. 主循环执行：

   * 更新LED状态；
   * 获取按键事件；
   * 切换运行/停止状态；
   * 刷新OLED显示内容；
   * 解析蓝牙数据包；
   * 更新PID参数与遥控目标；
5. TIM1中断周期执行实时控制：

   * 1 ms节拍；
   * 10 ms执行姿态解算与角度环控制；
   * 50 ms执行编码器测速、速度环与转向环控制。

---

### 3. 控制系统总体框架

项目采用典型的三环控制结构：
                  遥控前后指令
                        │
                        ▼
                  SpeedPID.Target
                        │
                        ▼
      当前平均速度 ──> 速度环PID ──> 目标倾角 AnglePID.Target
                                               │
                                               ▼
                              当前车身角度 ─> 角度环PID ─> 平衡PWM AvePWM
                                                                 │
                                                                 ├─────────────┐
                                                                 │             │
遥控转向指令                                                    左右轮合成输出
      │                                                          │             │
      ▼                                                          ▼             ▼
TurnPID.Target                                         LeftPWM          RightPWM
      │                                                    ▲                 ▲
      ▼                                                    │                 │
左右轮速度差 ───────> 转向环PID ───────> 差速PWM DifPWM ───┘                 └───

MPU6050姿态角 ──> 角度环PID ──> 基础PWM输出

基础PWM ± 差速PWM ──> 左右电机PWM ──> 小车运动
```

其中：

* **角度环** 是最内层控制环，作用是保持小车不倒；
* **速度环** 作用是控制小车前进、后退和停车；
* **转向环** 作用是控制左右轮差速，实现转弯。

## 四、各硬件模块详细说明

## 1. MPU6050姿态检测模块

### 1.1 模块作用

MPU6050用于测量车体运动状态，项目读取以下数据：

* 三轴加速度：`AX`、`AY`、`AZ`；
* 三轴角速度：`GX`、`GY`、`GZ`。

在当前工程中，平衡姿态主要依赖：

* `AX` 与 `AZ` 计算加速度倾角；
* `GY` 进行角速度积分；
* 二者通过互补滤波融合，得到车体倾角 `Angle`。

---

### 1.2 软件I2C通信

项目没有调用STM32硬件I2C外设，而是使用GPIO模拟I2C时序。

#### 引脚配置

| 信号  | STM32引脚 |
| --- | ------- |
| SCL | `PB10`  |
| SDA | `PB11`  |

#### 实现方式

`MyI2C.c` 实现了以下基础通信函数：

* `MyI2C_Start()`：产生I2C起始信号；
* `MyI2C_Stop()`：产生I2C停止信号；
* `MyI2C_SendByte()`：发送1字节；
* `MyI2C_ReceiveByte()`：接收1字节；
* `MyI2C_SendAck()`：发送应答；
* `MyI2C_ReceiveAck()`：接收应答。

使用软件I2C的好处是：

1. 引脚选择更灵活；
2. 移植到其他单片机更方便；
3. 便于初学者理解I2C总线时序。

---

### 1.3 MPU6050数据读取

`MPU6050.c` 完成以下功能：

1. 初始化MPU6050；
2. 配置电源管理寄存器；
3. 配置采样率；
4. 配置陀螺仪与加速度计量程；
5. 连续读取14字节传感器数据。

#### 初始化配置

当前工程配置为：

| 功能     | 设置                  |
| ------ | ------------------- |
| 采样分频   | `SMPLRT_DIV = 0x07` |
| 陀螺仪量程  | ±2000 °/s           |
| 加速度计量程 | ±16 g               |

数据读取函数：

```c
MPU6050_GetData(&AX, &AY, &AZ, &GX, &GY, &GZ);
```

---

### 1.4 姿态角估计

工程在 `TIM1_UP_IRQHandler()` 中每 10 ms 读取一次MPU6050数据，并执行姿态解算。

#### 加速度倾角

```c
AngleAcc = -atan2(AX, AZ) / 3.14159 * 180;
AngleAcc += 0.5;
```

#### 陀螺仪积分角度

```c
AngleGyro = Angle + GY / 32768.0 * 2000 * 0.01;
```

#### 互补滤波

```c
float Alpha = 0.01;
Angle = Alpha * AngleAcc + (1 - Alpha) * AngleGyro;
```

这表示：

* 加速度计角度用于长期校正漂移；
* 陀螺仪积分用于提供短时快速动态响应。

---

### 1.5 对应工程文件

| `Hardware/MyI2C.c`       | 软件I2C底层驱动             |
| `Hardware/MyI2C.h`       | 软件I2C函数声明             |

## 2. 电机驱动与PWM输出模块

### 2.1 模块作用

电机模块负责将控制器输出转换为实际轮子运动，包括：

1. 输出左右电机PWM；
2. 控制左右电机正反转；
3. 根据PID输出调节电机转速。

---

### 2.2 PWM调速实现

项目使用 `TIM2` 输出两路PWM。

#### PWM引脚

| 功能      | STM32引脚 | 定时器通道      |
| ------- | ------- | ---------- |
| 电机1 PWM | `PA0`   | `TIM2_CH1` |
| 电机2 PWM | `PA1`   | `TIM2_CH2` |

#### 定时器配置

```c
TIM_Period = 100 - 1;
TIM_Prescaler = 36 - 1;
```

在72 MHz主频下，PWM频率约为20 kHz，占空比范围为：

```text
0 ~ 100
```

PWM调节函数：

```c
PWM_SetCompare1(Compare);
PWM_SetCompare2(Compare);
```

---

### 2.3 电机正反转控制

电机方向由GPIO电平组合控制。

#### 电机方向引脚

| 电机  | 引脚1    | 引脚2    |
| --- | ------ | ------ |
| 电机1 | `PB12` | `PB13` |
| 电机2 | `PB14` | `PB15` |

在 `Motor_SetPWM()` 中：

* PWM为正：按正转方向输出；
* PWM为负：切换方向引脚，并输出绝对值占空比；
* PWM为0：电机不输出转矩。

函数形式：

```c
Motor_SetPWM(1, LeftPWM);
Motor_SetPWM(2, RightPWM);
```

---

### 2.4 对应工程文件

| 文件                 | 作用                     |
| ------------------ | ---------------------- |
| `Hardware/PWM.c`   | TIM2 PWM初始化与占空比设置      |
| `Hardware/PWM.h`   | PWM接口声明                |
| `Hardware/Motor.c` | 电机方向控制与PWM组合输出         |
| `Hardware/Motor.h` | 电机接口声明                 |
| `User/main.c`      | 根据PID输出计算左右轮PWM并调用电机驱动 |

## 3. 编码器测速模块

### 3.1 模块作用

编码器用于获取左右轮转速信息，为速度环和转向环提供反馈量。

工程中使用：

* `TIM3` 读取左轮编码器；
* `TIM4` 读取右轮编码器。

---

### 3.2 编码器测速实现

#### 引脚配置

| 编码器    | STM32引脚     | 定时器    |
| ------ | ----------- | ------ |
| 左轮A/B相 | `PA6`、`PA7` | `TIM3` |
| 右轮A/B相 | `PB6`、`PB7` | `TIM4` |

通过定时器编码器接口模式统计脉冲计数：

```c
TIM_EncoderInterfaceConfig(...);
```

每次调用 `Encoder_Get()`：

1. 读取当前计数值；
2. 清零计数器；
3. 返回该采样周期内的脉冲增量。

```c
LeftSpeed = Encoder_Get(1) / 44.0 / 0.05 / 9.27666;
RightSpeed = Encoder_Get(2) / 44.0 / 0.05 / 9.27666;
```

其中的比例参数用于将脉冲数换算为实际转速。

---

### 3.3 速度反馈在控制中的作用

编码器速度被进一步处理为：

```c
AveSpeed = (LeftSpeed + RightSpeed) / 2.0;
DifSpeed = LeftSpeed - RightSpeed;
```

其中：

* `AveSpeed` 用于速度环PID；
* `DifSpeed` 用于转向环PID。

---

### 3.4 对应工程文件

| 文件                   | 作用                     |
| -------------------- | ---------------------- |
| `Hardware/Encoder.c` | TIM3/TIM4编码器接口初始化、计数读取 |
| `Hardware/Encoder.h` | 编码器接口声明                |
| `User/main.c`        | 读取编码器并计算左右轮速度、平均速度和速度差 |

## 4. 按键输入模块

### 4.1 模块作用

按键模块负责检测用户手动输入。目前工程初始化了4个按键输入接口。

#### 引脚配置

| 按键编号 | STM32引脚 |
| ---- | ------- |
| Key1 | `PB1`   |
| Key2 | `PB0`   |
| Key3 | `PA5`   |
| Key4 | `PA4`   |

---

### 4.2 按键检测逻辑

按键采用上拉输入，按下时读到低电平。

在 `Key_Tick()` 中，每20 ms扫描一次按键状态，并在按键释放时记录一次按键事件。

主要函数：

* `Key_Init()`：初始化按键GPIO；
* `Key_GetState()`：读取当前按键状态；
* `Key_Tick()`：周期扫描与消抖；
* `Key_GetNum()`：获取一次性按键编号。

---

### 4.3 当前项目中的使用方式

主程序当前使用 `Key1` 切换小车运行状态：

* 未运行时按下：初始化PID，并启动平衡控制；
* 运行时按下：停止控制，电机输出清零。

主程序逻辑如下：

```c
if (KeyNum == 1)
{
    if (RunFlag == 0)
    {
        PID_Init(&AnglePID);
        PID_Init(&SpeedPID);
        PID_Init(&TurnPID);
        RunFlag = 1;
    }
    else
    {
        RunFlag = 0;
    }
}
```

---

### 4.4 对应工程文件

| 文件                                    | 作用                       |
| ------------------------------------- | ------------------------ |
| `Hardware/Key.c`                      | 按键初始化、状态读取、消抖与事件检测       |
| `Hardware/Key.h`                      | 按键接口声明                   |
| `User/main.c`                         | 使用按键控制小车启停               |

## 8. 蓝牙串口通信模块

### 8.1 模块作用

蓝牙串口用于与上位机或手机端交互，主要实现：

1. 在线调节PID参数；
2. 修改电机输出补偿；
3. 接收遥控摇杆数据；
4. 为后续按键控制协议预留接口。

---

### 8.2 通信协议

蓝牙串口使用 `USART2`。

| 功能 | STM32引脚 |
| -- | ------- |
| TX | `PA2`   |
| RX | `PA3`   |

串口参数同样为9600波特率。

接收数据采用如下帧格式：

```text
[数据内容]
```

中断函数 `USART2_IRQHandler()` 会：

1. 等待左括号 `[`；
2. 连续接收内容；
3. 遇到右括号 `]` 结束；
4. 将有效数据存入 `BlueSerial_RxPacket`；
5. 置位 `BlueSerial_RxFlag` 供主循环处理。

---

### 8.3 在线调参与遥控功能

#### 1）PID参数调节指令

格式：

```text
[slider,参数名,参数值]
```

示例：

```text
[slider,AngleKp,5.0]
[slider,SpeedKi,0.05]
[slider,TurnKp,4.0]
[slider,Offset,3]
```

可调参数包括：

* `AngleKp`、`AngleKi`、`AngleKd`；
* `SpeedKp`、`SpeedKi`、`SpeedKd`；
* `TurnKp`、`TurnKi`、`TurnKd`；
* `Offset`。

#### 2）遥控摇杆指令

格式：

```text
[joystick,LH,LV,RH,RV]
```

当前工程中：

```c
SpeedPID.Target = LV / 25.0;
TurnPID.Target  = RH / 25.0;
```

含义为：

* `LV`：控制前进/后退速度目标；
* `RH`：控制左右转向目标。

#### 3）按键指令预留

工程预留了：

```text
[key,Name,Action]
```

但当前版本尚未编写具体动作逻辑。

## 9. 定时器调度模块

### 9.1 模块作用

项目使用 `TIM1` 作为系统控制节拍定时器，负责周期性触发控制任务。

`Timer.c` 中配置为：

```c
TIM_Period = 1000 - 1;
TIM_Prescaler = 72 - 1;
```

在72 MHz系统时钟下，TIM1更新中断周期为：

```text
1 ms
```

---

### 9.2 周期任务分配

`TIM1_UP_IRQHandler()` 中的周期任务如下：

| 任务           |                   调用周期 | 功能                      |
| ------------ | ---------------------: | ----------------------- |
| `Key_Tick()` | 1 ms进入，内部20 ms执行一次有效扫描 | 按键消抖                    |
| 姿态采集与角度环     |                  10 ms | 读取MPU6050，计算角度，更新角度环PID |
| 编码器测速与速度/转向环 |                  50 ms | 计算车速，更新速度环PID与转向环PID    |

这种调度方式体现了典型的多速率控制思想：

* 姿态环响应要快；
* 速度与转向变化相对更慢。

## 五、控制算法说明

## 1. 三环控制结构

项目采用：

1. 角度环；
2. 速度环；
3. 转向环。

三者关系如下：

```text
速度环输出 -> 角度环目标值
转向环输出 -> 左右轮差速PWM
角度环输出 -> 左右轮共同基础PWM
```

---

## 2. 角度环

角度环是系统最核心的环节，用于维持小车直立。

输入：

* 当前倾角 `Angle`；
* 目标倾角 `AnglePID.Target`。

输出：

```c
AvePWM = -AnglePID.Out;
```

用于构造左右电机基础输出。

当倾角超过 ±50° 时，系统自动停止：

```c
if (Angle > 50 || Angle < -50)
{
    RunFlag = 0;
}
```

---

## 3. 速度环

速度环用于控制小车前进、后退与静止。

输入：

* 当前平均速度 `AveSpeed`；
* 目标速度 `SpeedPID.Target`。

输出：

```c
AnglePID.Target = SpeedPID.Out;
```

这意味着速度环并不直接控制PWM，而是通过改变“目标倾角”来间接控制小车运动：

* 目标倾角前倾，小车前进；
* 目标倾角后仰，小车后退。

---

## 4. 转向环

转向环根据左右轮速度差控制转向。

输入：

* 当前差速 `DifSpeed`；
* 目标差速 `TurnPID.Target`。

输出：

```c
DifPWM = TurnPID.Out;
```

左右电机最终输出：

```c
LeftPWM  = AvePWM + DifPWM / 2;
RightPWM = AvePWM - DifPWM / 2;
```

由此实现差速转向。

---

## 5. PID算法实现

PID控制器封装在：

```text
User/PID.c
User/PID.h
```

### PID结构体内容

`PID_t` 包含：

* 目标值；
* 当前值；
* 上一次实际值；
* 输出值；
* `Kp`、`Ki`、`Kd`；
* 当前误差、历史误差；
* 积分累计；
* 积分限幅；
* 输出限幅；
* 输出死区补偿。

### 当前实现特点

1. 支持积分限幅，避免积分饱和；
2. 支持输出限幅，避免PWM超范围；
3. 支持电机死区补偿 `OutOffset`；
4. 微分项使用“测量值微分”：

```c
-p->Kd * (p->Actual - p->Actual1)
```

该形式可减弱设定值突变时的微分冲击。

### 2. 主循环阶段

主循环主要负责非强实时任务：

1. LED运行状态显示；
2. 按键读取；
3. 小车启停切换；
4. OLED数据显示；
5. 蓝牙指令解析；
6. 参数更新与遥控目标更新。

---

### 3. 中断控制阶段

TIM1中断中完成强实时控制：

#### 每10 ms：

1. 读取MPU6050；
2. 修正陀螺仪零偏；
3. 计算加速度角度；
4. 计算陀螺积分角度；
5. 互补滤波获得最终角度；
6. 执行角度环PID；
7. 输出左右轮PWM。

#### 每50 ms：

1. 读取编码器；
2. 计算左右轮速度；
3. 计算平均速度与差速；
4. 执行速度环PID；
5. 执行转向环PID；
6. 更新角度环目标值与差速PWM。

3. PWM电机控制；
4. 编码器测速；
5. 多速率实时控制调度；
6. 平衡车三环PID控制框架；
7. 蓝牙串口在线调参与人机交互。
